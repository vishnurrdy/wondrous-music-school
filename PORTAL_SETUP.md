# Wondrous Music School — Portal Setup\n\n## 1. Supabase\nCreate a Supabase project and run supabase/schema.sql in SQL Editor.\n\nCreate two Auth users:\n- one student account\n- one school admin account\n\nAfter the admin account is created, copy its Auth user UUID and run:\nupdate public.profiles set role='admin' where id='ADMIN-USER-UUID';\n\n## 2. Portal configuration\nSet SUPABASE_URL and SUPABASE_PUBLISHABLE_KEY in config.js.\nDo not use the Supabase service-role key in the browser.\n\n## 3. Payment\nThe portal currently uses Razorpay checkout.\nDeploy the create-payment-order-v2 and verify-payment-v2 Edge Functions.\nSet RAZORPAY_KEY_ID, RAZORPAY_KEY_SECRET and SUPABASE_SERVICE_ROLE_KEY as server-side secrets.\nNever commit the secret key to GitHub.\n\n## 4. Flow\nStudent: Register -> email confirmation -> login -> enrollment -> Pay Now -> gateway -> server-side signature verification -> payment history.\n\nAdmin: Login -> students -> enquiries -> enrollments -> payment records.\n\n## 5. Instructor images\nThe database contains the two instructor records. Add the supplied instructor photographs to assets/ and set image_url in public.instructors.\n\n## 6. Ukulele\nUkulele is included with a starter fee of INR 1,200. Change the fee in the courses table if required.\n\n## 7. Production security\nEnable your hosting provider WAF/firewall/rate-limiting rules. Keep admin MFA enabled where available.
